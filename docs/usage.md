# 体检页使用

体检页 `/` 是主入口：贴入或上传 `redis.conf`，逐项对照当前版本的官方默认值，标出被改过、未知、已废弃和危险的配置，可编辑并导出新 conf。需要从零生成配置时见[生成配置向导](configurator.md)。

## 导入

- 粘贴文本、上传 `.conf` 文件，或把文件直接拖进编辑区。
- 顶部选 Redis 版本（6.2 到 8.10 共 10 条 minor 线，每条线取最新正式 patch，显示发布日期）。

## 注释、搜索与查找

- 「内联注释」三档：只补缺失（默认）/ 全部显示 / 关闭。
- `Ctrl+K`（Mac 上 `⌘K`）搜索配置项；文件里没有的项可以直接插到对应分节。
- `Ctrl+F`（Mac 上 `⌘F`）在当前栏查找：左右栏各自独立，支持区分大小写、全词与正则，`Enter` / `Shift+Enter` 切换命中，`Esc` 关闭。

## 体检结果

底部默认是「体检结果」：按告警、缺失、已改、未知、已移除、版本不支持、重复分组列出计数与明细，点击明细定位到编辑器；缺失项可直接补入官方默认值，官方无默认值的（如 `bind`）会打开搜索面板。

## 配置对比

- 底部「配置对比」是 IDEA 风格的并排 diff：左行号 / 你的配置 / 箭头 / 官方默认 / 右行号，修改行左红右绿并做词级高亮，未改行折叠；点箭头可把单行改回官方默认值。
- 「只看差异」开关在对比页头，同时作用于编辑器和对比表。
- diff 行组只占一个 Tab 停靠点：`↑` / `↓` 移动，`Home` / `End` 到首尾，`Enter` 跳转且焦点留在 diff，`Esc` 回到编辑器；行内 `»` 按钮可单独 `Tab` 聚焦。

## 导出

- 导出三种：原样导出、补全官方注释后导出、还原密码后导出。
- 导出按钮右侧（竖线分隔）的 GitHub 图标在新窗口打开[仓库首页](https://github.com/ZRoger95/ZiLucidRedis)，生成向导页头也有同一个入口。

## 密码怎么处理

导入时，`requirepass`、`masterauth`、`tls-key-file-pass`、`tls-client-key-file-pass` 和 ACL `user ... >pass` 的值会被就地替换成 `${env_requirepass}` 这类占位符：

- 编辑器里看到的、`localStorage` 里存的、默认导出的，都是占位符；
- 原始密码只保留在本次会话的内存里，刷新即丢；
- 需要明文时才用「还原密码后导出」，会有一次二次确认。

注意：**Redis 本身不解析环境变量**。占位符需要部署侧（docker-entrypoint、envsubst、confd 等）替换，否则实例会带着字面量启动。
