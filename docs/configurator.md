# 生成配置向导

从体检页右上角「生成配置」进入 `/configurator`（地址不要带末尾斜杠，静态托管下会白屏）。体检、对比与导出见[体检页使用](usage.md)。

## 场景入口

版本步有三个场景入口与一个逐项入口：

- 「单机单实例」用 4 问生成推荐值——部署画像（独占 / 混部）、资源（规格档位或内存预算，可填小数、单位可选 GB / MB）、持久化（不开 / 仅 RDB / 仅 AOF / 混用）、访问面（仅本机 / 内网 / 公网）。
- 「一主二从三哨兵」用 3 问（资源、持久化、网络与认证）生成 3 份 redis 配置（主库 / 从库 1 / 从库 2）与 3 份哨兵配置（哨兵 1–3）。
- 「三主三从集群」用 3 问（资源、持久化、网络与认证）生成 6 份 redis 配置（主库 1–3、从库 1–3）与 `redis-cli --cluster create` 初始化命令。

答完直达完成页。

## 完成页

- 场景完成页列出「预设改了什么」（每条带理由，可跳到对应区域修改）与「系统层必做项」（overcommit、透明大页、somaxconn、哨兵跨机部署、集群槽分配等进不了 conf 的机器设置）；内网 / 公网访问必填密码，重新回答问卷会覆盖预设项的修改。
- 完成页可预览并下载：单机场景下载 `redis-<版本>.conf`，一主二从三哨兵与三主三从集群场景按标签逐份下载对应节点配置；单机场景还可「带回体检页」继续检查（密码会先替换成 `${env_*}` 占位符）。

## 逐项配置

- 按官方 `redis.conf` 的区域一区一步；左侧导航可跳转并显示各步改动数。场景预设填过的字段标「来自场景」，改过后标「已手动修改」。
- 每个字段用官方默认值做占位提示，只有输入过的项才取消注释写入；未改动的行保持官方注释原样。
- `include`、`loadmodule`、`user`、`rename-command` 在对应区域单独填写；`config.c` 里有、官方模板未收录的指令放在最后的「其他」步。

## 草稿与密码

草稿保存在浏览器本地；`requirepass` 与 ACL 用户行不落盘，刷新后需要重填。
