# 功能地图（用户视角）

供 Agent 驱动运行时验证使用：每行给出功能、路由、到达方式与选择器、以及「什么证明它工作」。选择器复用产品现有 aria-label / role / 中文文案，产品代码不含 `data-testid`。可执行核对见 `e2e/smoke.spec.ts`；设计与取舍见 [运行时验证层设计](../superpowers/specs/2026-11-24-runtime-verification-design.md)。

## 体检页 `/`

| 功能             | 到达方式与选择器                                                                                                                    | 什么证明它工作                                             |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 空状态与导入入口 | heading「贴一份 redis.conf 进来看体检结果」；按钮「载入官方完整配置」「选择文件」；工具栏按钮「上传 conf」+ 隐藏 `input[type=file]` | 上传后出现导入通知，编辑器渲染内容                         |
| 拖拽 / 键入导入  | 拖文件到页面（main onDrop）；已有内容时在 `.cm-content` 键入或粘贴                                                                  | 文本进入编辑器并触发体检计数                               |
| 版本切换         | combobox「Redis 版本」                                                                                                              | 官方面板基线与字典随版本变化                               |
| 内联注释三档     | combobox「内联注释显示方式」→ 只补缺失 / 全部显示 / 关闭                                                                            | 编辑器上方注释块显隐变化                                   |
| 中文摘要开关     | switch「中文摘要」                                                                                                                  | 详情与注释中的中文摘要显隐                                 |
| 搜索面板         | 按钮「搜索配置项」或 `Ctrl+K`                                                                                                       | 面板出现，可把缺失项插到对应分节                           |
| 栏内查找         | `Ctrl+F`（左右栏独立）                                                                                                              | 查找条出现，命中可切换                                     |
| 体检分组         | region「体检结果」；分组 `ul[aria-label=<分组名>]`；明细项按钮                                                                      | 分组计数与明细正确，点击定位编辑器                         |
| 缺失补入         | 体检缺失项按钮；无官方默认值时打开搜索面板                                                                                          | 编辑器插入官方默认值行                                     |
| 配置对比         | tab「配置对比」→ region「配置对比」；switch「只看差异」；行内按钮 aria-label「将 <指令名> 改回官方默认值」                          | 并排 diff 与词级高亮；单行可恢复默认                       |
| 配置项说明       | tab「配置项说明」                                                                                                                   | 光标行详情、默认值与插入默认按钮                           |
| 导出三模式       | 按钮「导出」→ menuitem「原样导出（密码保持占位符）」「补全官方注释后导出」「还原密码后导出…」                                       | 触发下载；原样含 `${env_*}` 不含明文；还原模式先弹二次确认 |
| 清空             | 按钮「清空」                                                                                                                        | 回到空状态                                                 |
| 持久化往返       | reload 页面                                                                                                                         | `localStorage['zilucid:state']` 恢复文本，且为占位符形态   |

## 生成向导 `/configurator`

| 功能         | 到达方式与选择器                                                                          | 什么证明它工作                                                                                                                                                            |
| ------------ | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 入口         | 体检页按钮「生成配置」                                                                    | URL 为 `/configurator`，h1「生成配置」                                                                                                                                    |
| 版本步       | combobox「选择 Redis 版本」                                                               | 选版本后可经导航进入区域步骤                                                                                                                                              |
| 步骤导航     | nav「配置步骤」                                                                           | 各步改动数徽标与底栏「已改 N 项」同步，可跳转                                                                                                                             |
| 字段填写     | region「当前步骤」；输入控件 aria-label=指令名（bool 为 switch）                          | 只有输入过的项取消注释写入；冒烟已核对 bool / 数值 / enum / special 多行 / 敏感五类代表控件                                                                               |
| 自由行       | textarea「ACL 用户规则」；输入「命令 N」「新名 N」「路径 N」                              | include / loadmodule / user / rename-command 正确写入（save 多行展开、user 原样、rename-command 带引号）                                                                  |
| 完成页       | heading「生成结果预览」与 `pre[aria-label=生成结果预览]`；按钮「下载 conf」「带回体检页」 | 预览含生效行；下载先弹含「明文密码」的二次确认，得 `redis-<版本>.conf` 且含改动与明文；带回体检页后密码为 `${env_*}` 占位符、体检计数正常                                 |
| 硬加载与刷新 | 直接打开 `/configurator` 或 reload                                                        | 向导正常渲染不白屏；非敏感草稿恢复、敏感字段为空且提示「敏感值不保存」，localStorage 无明文。vite preview 的 SPA fallback ≠ GitHub Pages `404.html`，此核对不等价线上验证 |
